# SPEC — 產品規格

## 1. 背景與目標

單一使用者(JLPT N4 程度日語學習者)的個人學習工具。內容來源為《大家的日本語》初級 I・II 共 50 課,已於建置期由 PDF 抽取為結構化 JSON(見 `docs/PIPELINE.md`)。目標:

- 以 FSRS 間隔重複高效記憶單字
- 隨時可查各課文法與例句
- 首次載入後**完全離線**可用,可安裝為 PWA(手機為主要使用裝置)

## 2. 使用者與情境

- 一名使用者、無帳號系統
- 通勤與零碎時間做 SRS 複習;在家備考時做整課測驗與文法查閱

## 3. 功能需求

### F1 課程瀏覽

- **F1.1** 課程列表:50 課,顯示課號、標題、單字數、學習進度(未開始/進行中/已完成)
- **F1.2** 課程內頁:単語/文型/会話 三個分頁
- **F1.3** furigana 顯示切換(全域設定 + 頁面內快速切換),以原生 `<ruby>` 渲染
- **F1.4** 單字逐項:點擊發音(TTS)、「加入複習」(單字或整課)

### F2 SRS 複習(核心功能)

- **F2.1** 今日佇列 = 到期卡片 + 新卡(受每日新卡上限約束,預設 10)
- **F2.2** 卡片正面:日文(furigana 受設定控制);背面:讀音 + 中文釋義 + 詞性 + 所屬課
- **F2.3** 四鍵評分:Again / Hard / Good / Easy,按鍵上顯示預估下次間隔
- **F2.4** 評分即時更新 FSRS 卡片狀態並寫入複習紀錄(logs)
- **F2.5** session 結算頁:本次數量、各評分分布、明日到期預估
- **F2.6** 鍵盤操作:空白鍵翻面、數字 1–4 評分

### F3 測驗

- **F3.1** 以課為單位出題;題型:四選一(日→中、中→日)與輸入題(看中文與漢字,輸入假名)
- **F3.2** 選擇題干擾項:優先取同課同詞性;不足時擴至鄰近課;不得重複、不得含正解
- **F3.3** 輸入題以 WanaKana 正規化後比對(羅馬字輸入自動轉假名;平/片假名視為等同)
- **F3.4** 結果頁:分數、錯題清單、一鍵將錯題加入 SRS 複習

### F4 文法速查

- **F4.1** 跨課文法點列表(課號排序),可跳至課程內頁對應錨點
- **F4.2** MiniSearch 客戶端全文檢索:涵蓋文型、解說、例句與單字

### F5 統計

- **F5.1** 複習熱力圖(過去 12 週)
- **F5.2** 到期預測(未來 7 / 30 天)
- **F5.3** 留存率(由 logs 計算)與各課學習進度
- 全部以 Recharts 呈現;資料來源僅 IndexedDB,聚合邏輯集中於 `src/lib/stats.ts`

### F6 設定與資料

- **F6.1** 每日新卡上限、每日複習上限、TTS 開關、furigana 預設值
- **F6.2** 匯出全部使用者資料為單一 JSON 檔;匯入(覆蓋前雙重確認)
- **F6.3** 重置所有進度(雙重確認)

## 4. 非功能需求

- **N1 離線**:首次載入後,所有頁面與 50 課內容離線可用(Service Worker 預快取)
- **N2 PWA**:可安裝、standalone 顯示、自有 icon;Lighthouse PWA 檢查通過
- **N3 iOS Safari**:啟動時呼叫 `navigator.storage.persist()`;未安裝時提示加入主畫面
- **N4 效能**:首頁 JS bundle(gzip)< 200 KB;課程頁間切換無感
- **N5 純靜態**:無任何 runtime 後端,可部署於任何靜態主機
- **N6 版權**:內容僅個人使用;部署必須置於存取控制之後(Cloudflare Access)

## 5. v1 範圍外(明確不做)

- 跨裝置同步、帳號系統
- 手寫漢字練習、原版 CD 音檔聽力
- 文法點的 SRS 卡(資料模型已預留 ID 空間,v2 再做)
- 自訂卡片、自訂牌組
