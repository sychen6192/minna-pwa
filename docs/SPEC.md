# SPEC — 產品規格

## 1. 背景與目標

單一使用者(JLPT N4 程度日語學習者)的個人學習工具。內容來源為《大家的日本語》初級 I・II 共 50 課,已於建置期由 PDF 抽取為結構化 JSON(見 `docs/PIPELINE.md`)。目標:

- 以 FSRS 間隔重複高效記憶單字
- 隨時可查各課文法與例句
- 首次載入後**完全離線**可用,可安裝為 PWA(手機為主要使用裝置)

## 2. 使用者與情境

- 一名使用者、無帳號系統
- 通勤與零碎時間做 SRS 複習;在家備考時做整課測驗與文法查閱

## 3. 功能需求

### F1 課程瀏覽

- **F1.1** 課程列表:50 課,顯示課號、標題、單字數、學習進度(未開始/進行中/已完成;補充單字不計入)。返回列表時還原捲動位置
- **F1.2** 課程內頁:単語/文型/会話 三個分頁(分頁存於網址 hash,返回本頁時還原分頁;分頁列黏在頂端);標頭有「測驗本課」、練習入口(活用練習、例句重組)與上一課/下一課(‹ › 箭頭)連結
- **F1.3** furigana 顯示切換(全域設定 + 頁面內快速切換),以原生 `<ruby>` 渲染。課程頁初始值取全域設定,頁內切換只影響本頁;隱藏時含漢字讀音的字不顯示重音標記(F1.5 會寫出完整讀音)
- **F1.4** 單字逐項:點擊發音(TTS)、「加入複習」(單字或整課;整課不含「補充單字(自行練習發音)」,加入後顯示實際新加入字數與「開始複習」連結)。段落標記 note(読み物/会話/補充單字)以小徽章顯示
- **F1.5** 單字重音標記(2026-07-10 追加):東京式ピッチアクセント視覺標記(高拍上線、下降核豎線、平板尾延伸線、[n] 型號);`vocab.accent` 於建置期由 kanjium 辭典回填,無資料之單字不顯示(寧缺勿錯)。拍數只計假名(…、〜［］等記號原樣顯示、不計拍);純假名字(表面即讀音)以重音標記直接作為標題,單字列與卡片背面不再重複列讀音(2026-09-29 修訂)
- **F1.6** 教材中文標點一致(2026-09-30 追加,Phase 12):單字釋義、搭配 note、文法解說、例句與会話中譯的「，；：？！（）」一律為全形(千分位如 15,000 保留半形;小型變體 ﹐﹑﹖、ASCII 引號與 ～ 一併統一為 ，、？“”〜),於建置期寫回資料(不是顯示時轉換),各畫面、搜尋與測驗看到的文字一致。App 介面文案不在此列

### F2 SRS 複習(核心功能)

- **F2.1** 今日佇列 = 到期卡片 + 新卡(受每日新卡上限約束,預設 10)。上限以「學習日」計(凌晨 4 點換日,2026-09-28 修訂):同一學習日內重開複習頁不得再發新額度;到期判定以學習日為單位(當日到期即可複習)。雙向卡同一字的兩個方向不在同一學習日出現
- **F2.2** 卡片正面:日文(furigana 受設定控制);背面:讀音(含重音標記,F1.5)+ 中文釋義 + 詞性 + 所屬課 + 搭配提示(`vocab.note`,段落標記除外)+ 同課語境例句(中譯與發音鈕;依詞邊界找本課最短的文型例句或会話句,動詞全課沒有ます形時改配活用形,如 会います →「会いましょう」;寧可漏、不可誤配,找不到不顯示)。回想卡(中→日)正面為中文釋義 + 詞性・課號(消除同義詞歧義),搭配提示只在翻面後顯示
- **F2.3** 四鍵評分:Again / Hard / Good / Easy,按鍵上顯示預估下次間隔
- **F2.4** 評分即時更新 FSRS 卡片狀態並寫入複習紀錄(logs)
- **F2.5** session 結算頁:本次數量、各評分分布、明日到期預估、本次答錯的字與重看次數、今日目標與連續天數;今日佇列仍有卡(如略過空出新卡額度)時主行動為「繼續複習」
- **F2.6** 鍵盤操作:空白鍵翻面、數字 1–4 評分(重看項:1 = 還不熟、3 = 記住了)
- **F2.7** session 內重看(2026-09-28 追加):評「重來」的卡於本次 session 稍後再出現一次(僅曝光,不寫入 FSRS 與 logs);可復原上一次評分或略過

### F3 測驗

- **F3.1** 以課為單位出題(10 題);題型:四選一(日→中、中→日)與輸入題(看中文與漢字,輸入假名);聽力題(聽發音選中文,僅在 TTS 開啟且有日語語音時)與例句填空(本課例句挖空選詞,2026-09-29 追加)。開始前以「題型」開關選擇(預設全選,聽力不可用時停用並說明原因;至少保留一種;選擇存於設定、下次沿用),一鍵開始(按鈕顯示題數:本課適合所選題型的字不足 10 個時較少);每回合從本課適合的字隨機均勻抽題(再測一次重新抽),題型依序輪替,輸入、填空、聽力只出給抽中的字裡適合者,不足時改出其他已選題型(輸入、填空優先中→日,聽力優先日→中),因此填空只在抽到有例句的字時出現。輸入題只出含漢字讀音、且表面不含「〜」「…」的字(純假名字題幹即答案),題幹已寫出某個答案者(（）內外其一為假名,如 トイレ（お手洗い）)亦不出;「補充單字(自行練習發音)」不出題(可當干擾項)
  - 聽力:題目出現時自動朗讀一次(在點擊事件內)、可「再聽一次」,作答後顯示單字(含讀音);含漢字者朗讀表面形(引擎依辭典決定重音),單一漢字、含數字、同形異讀(降ります、明日…)與並列寫法改讀假名;kana 含記號者(すき［な］、おっと／しゅじん)與接頭/接尾詞(〜君、…時)不出
  - 例句填空:以語境例句的詞邊界比對找本課最短的文型例句或会話句,把單字表面形挖空(只用表面形本身的命中,動詞以活用形配到的例句不出;同句只挖一處,句中另有同字者不選;不拆帶讀音的漢字段),顯示中譯;慣用語不出,含「→」的對照行、正規化後等於單字本身與中譯標示較晚課次的例句不選(会話標題不是台詞,不在候選內);同一回合同一句例句只用一次(沒有其他可出的字時才重複)
- **F3.2** 選擇題干擾項:優先取同課同詞性;不足時擴至鄰近課;不得重複、不得含正解。聽力的中文選項彼此不重複且不含讀音相同的字;填空的日文選項彼此不重複、不含教材記號(［］〔〕〜… 等);聽力與填空都排除「可互換」的字(同時當選項會都算對):中文意思去掉括號說明後有共同詞(では／それでは、中／奥)、意思提到對方(どこ／どちら「どこ 的禮貌形」)、同類こそあど詞且中譯同為這／那／哪(あそこ／そちら)
- **F3.3** 輸入題以 WanaKana 正規化後比對(羅馬字輸入自動轉假名,「ん」打 n 或 nn 皆可;平/片假名視為等同;長音「ー」等同處理);教材表記中的［］〔〕視為可省略、（）與「／」視為替代答案
- **F3.4** 結果頁:分數、錯題清單、一鍵將錯題加入 SRS 複習(未加入者建立、已暫停者恢復、未到期者提前至今日;今日已複習過的字受兄弟卡 bury 限制,提前至下一學習日),並顯示實際結果(今日複習額度已用完時不宣稱今天出現);再測一次、下一課測驗

### F4 文法速查

- **F4.1** 跨課文法點列表(課號排序),可跳至課程內頁對應錨點(client 導覽亦同)
- **F4.2** MiniSearch 客戶端全文檢索:涵蓋文型、解說、例句與單字;單字結果跳至課程內頁該字並短暫高亮。查詢字串存於網址 `?q=`,返回時還原;搜尋框黏在頂端

### F5 統計

- **F5.1** 複習熱力圖(過去 12 週)
- **F5.2** 到期預測(未來 7 / 30 天)
- **F5.3** 留存率(由 logs 計算)與各課學習進度
- 圖表以 Recharts 呈現(熱力圖除外——Recharts 無 heatmap 元件,以自製 CSS grid 實作);資料來源僅 IndexedDB,聚合邏輯集中於 `src/lib/stats.ts`

### F6 設定與資料

- **F6.1** 每日新卡上限、每日複習上限、TTS 開關(關閉時不顯示任何發音鈕)、furigana 預設值
- **F6.2** 匯出全部使用者資料為單一 JSON 檔;匯入(覆蓋前雙重確認)
- **F6.3** 重置所有進度(雙重確認;清除卡片、複習紀錄與進度,保留設定)

### F7 練習活動(2026-09-29 追加;皆為單次練習,不寫入 SRS,SPEC §5 文法 SRS 仍不做)

- **F7.1** 課程頁自我測驗:単語分頁可遮住中文或日文,點擊逐項揭示;詞性篩選(名詞/動詞/形容詞/其他);文型與会話可隱藏中譯
- **F7.2** 会話朗讀與角色扮演:逐句與全部朗讀(Web Speech,目前句高亮、可停止);扮演時所選角色的台詞先遮住(中譯作為開口提示,隱藏中譯時一併隱藏),輪到時暫停等待使用者;会話標題(資料欄位 `dialogueTitle`,教材有標題的課才有,目前 L15/L23/L24/L41)以小標顯示在台詞上方,中譯隨「隱藏中譯」;標題不是台詞,不列入播放、扮演與例句重組(2026-09-30 修訂:原為会話第一行,執行期判定);TTS 關閉或無日語語音時隱藏全部播放與扮演
- **F7.3** 活用練習(`/drill`):動詞與形容詞活用形(基本形:ます系、て、た、ない、なかった、辞書形;形容詞否定/過去/て形/〜く・に(なります),普通形與丁寧體;進階形:可能、意向、命令/禁止、條件ば(形容詞 〜ければ/〜なら)、受身、使役,可能/受身/使役以辞書形作答),依教材導入課次與學習進度開放;四選一(干擾項為常見錯誤活用)與輸入題;答錯可連到該形的文法解說。活用形由規則推導,不確定者排除(寧缺勿錯)
- **F7.4** 例句重組:以教材分かち書き空格把例句與会話切塊(抽取時多出的空格併回),依中譯排回原句(對應 JLPT 文法問題2);6 塊以上固定首尾;語序以教材為準
- **F7.5** 助詞搭配(`/drill` 的「助詞」分頁,與活用練習共用範圍):取單字 note 中教材原有的搭配出選助詞題——「〔名詞 助詞〜〕」(〔たばこを〜〕→ たばこ（　）吸います)與名詞單字的「〔〜を します〕」(宿題（　）します),不補新的搭配;從 を/に/が/で/へ/と 出 4 個選項(方向的 に/へ 選項中至多一個;已知同義也自然的助詞不當干擾項,干擾項因此不足者不出題),標示為教材搭配並註明其他助詞有時也自然;回饋顯示完整搭配(ruby)、朗讀與中譯;每回合 10 題,「〜を します」型至多 2 題;排除補充單字

## 4. 非功能需求

- **N1 離線**:首次載入後,所有頁面與 50 課內容離線可用(Service Worker 預快取)
- **N2 PWA**:可安裝、standalone 顯示、自有 icon;Lighthouse PWA 檢查通過(Lighthouse 12 起移除 PWA 類別,以 lighthouse@11 PWA 類別為準;報告見 `docs/reports/`)
- **N3 iOS Safari**:啟動時呼叫 `navigator.storage.persist()`;未安裝時提示加入主畫面
- **N4 效能**:首頁 JS bundle(gzip)< 200 KB;課程頁間切換無感
- **N5 純靜態**:無任何 runtime 後端,可部署於任何靜態主機
- **N6 版權**:內容僅個人使用;repo 維持 private、原始 PDF 永不入庫。部署為公開網址(2026-07-10 修訂:捨棄原 Cloudflare Access 方案,改為免登入公開使用,風險由使用者自行承擔),以 noindex(meta robots + `X-Robots-Tag`)降低曝光,不主動散佈網址
